## ✨ Sobre o projeto

O **Library AI Assistant** é um projeto pessoal que une desenvolvimento de software, banco de dados e Inteligência Artificial para tornar a consulta de informações de uma biblioteca mais simples e acessível.

A proposta é desenvolver um assistente inteligente capaz de ajudar usuários a encontrar livros, consultar disponibilidade e acessar informações do acervo por meio de uma experiência intuitiva e conversacional.

Mais do que desenvolver uma aplicação, este projeto representa uma oportunidade de explorar tecnologias, integrar diferentes ferramentas e transformar conhecimentos em soluções práticas.

## 🎯 Objetivos

- Consultar livros por título ou autor.
- Verificar a disponibilidade de exemplares.
- Consultar informações sobre empréstimos.
- Integrar Python a um banco de dados SQL Server.
- Explorar recursos de Inteligência Artificial para buscas e interações conversacionais.

## 🛠️ Tecnologias utilizadas

| Tecnologia | Aplicação no projeto |
|---|---|
| Python | Lógica da aplicação e backend |
| SQL Server | Armazenamento e gerenciamento dos dados |
| pyodbc | Integração entre Python e SQL Server |
| Git e GitHub | Versionamento e documentação |
